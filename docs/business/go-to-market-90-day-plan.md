# 90-Day Go-To-Market Plan

## Goal

Land the first 5 paying Hatchkit customers, validate the Growth package, and turn the delivery process into a repeatable HighLevel snapshot.

## Days 1-14: Build The Sales Foundation

Outcomes:

- SunScale demo account is ready.
- Sales page and demo script are ready.
- Pricing and onboarding docs are ready.
- Outreach list has at least 100 reptile sellers.

Actions:

- Record a 5-7 minute demo video.
- Create a one-page sales PDF from the sales packet.
- Build a list from personal network, reptile shows, Instagram, Facebook groups, MorphMarket sellers, and referrals.
- Message 10 sellers per day.
- Ask your friend for 3 warm introductions.

## Days 15-30: First Pilot Customers

Outcomes:

- 10 discovery calls booked.
- 3 demos completed.
- 1-2 paid pilot customers closed.

Actions:

- Offer Starter or Growth only. Avoid custom work unless paid.
- Use the 14-day launch promise.
- Collect exact objections and add them to the sales playbook.
- Build each pilot using the implementation SOP.
- Run a launch review after the first 7 days.

## Days 31-60: Turn Delivery Into A System

Outcomes:

- 3 paying customers live.
- HighLevel snapshot has repeatable fields, tags, pages, and workflows.
- Support playbook is updated from real customer questions.

Actions:

- Standardize the onboarding form.
- Build a launch QA checklist for every account.
- Track setup hours by package.
- Convert repeated requests into add-ons.
- Ask every happy customer for a testimonial and referral.

## Days 61-90: Push Toward Repeatable Sales

Outcomes:

- 5 paying customers.
- At least $1,000/mo in MRR.
- Clear proof points from real sellers.

Actions:

- Publish case-study style posts.
- Run a webinar or live demo for reptile sellers.
- Create a referral offer for existing customers.
- Start a monthly "availability marketing" service add-on.
- Decide whether to build custom software beyond HighLevel based on repeated customer pain.

## Weekly Scorecard

Track every Friday:

- New prospects added
- Outreach messages sent
- Replies received
- Discovery calls booked
- Demos completed
- Proposals sent
- New customers
- Setup revenue
- Monthly recurring revenue
- Active customer issues
- Testimonials collected
