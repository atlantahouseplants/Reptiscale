# SunScale Demo Visual Assets

Last updated: 2026-06-02

These are project-local placeholder assets for the SunScale Geckos demo showroom.

## Files

- `sunscale-logo.svg`: badge-style demo logo.
- `hero-pattern.svg`: storefront hero background.
- `nova-placeholder.svg`: Nova animal card placeholder.
- `mango-placeholder.svg`: Mango animal card/detail placeholder.
- `echo-placeholder.svg`: Echo animal card placeholder.
- `pepper-placeholder.svg`: Pepper animal card placeholder.
- `starter-guide-cover.svg`: lead magnet cover placeholder.
- `qr-placeholder.svg`: non-functional QR image placeholder.
- `sunscale-reference-sheet.png`: generated bitmap concept sheet for the showroom look.

## Replacement Guidance

Before a real sales demo, replace placeholders with:

- actual breeder logo or final generated logo
- real gecko photos, if available
- a real QR code pointing to the live starter guide or VIP page
- HighLevel screenshots after the new demo subaccount exists

Do not use real customer photos or real buyer information without permission.
