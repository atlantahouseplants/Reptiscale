# HatchKit Brand Kit Reference

## Brand Feel

Smart, clean, breeder-business tool, safe shipping, organized, not reptile-only.

Think: breeder command center + shipping safety + social media simplicity.

HatchKit is not a pet store brand. It should look like business software, not cute animals.

## Colors

### Main Colors

| Name | Hex | Use |
| --- | --- | --- |
| Deep Navy | `#102A43` | Trust and structure |
| Hatch Blue | `#2F80ED` | Tech and software |
| Fresh Teal | `#00B8A9` | Safe movement and shipping |
| Warm Eggshell | `#FFF7E6` | "Hatch" warmth |
| Charcoal | `#1F2933` | Text and dark backgrounds |

### Accent Colors

| Name | Hex | Use |
| --- | --- | --- |
| Soft Green | `#B9FBC0` | Success and positive indicators |
| Coral Alert | `#FF6B6B` | Alerts, shipping warnings, and deadlines |

| Role | Font |

## Logo Reference

Source reference: [hatchkit-logo-reference.jpg](brand-assets/hatchkit-logo-reference.jpg)

Use the open-box mark with an egg, blue crack line, and teal check as the primary visual direction.
The wordmark should emphasize `Hatch` in Deep Navy and `Kit` in Hatch Blue on light backgrounds.
On dark backgrounds, use a light `Hatch` treatment with Hatch Blue or a brighter blue for `Kit`.
