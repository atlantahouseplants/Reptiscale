# Customer Onboarding Playbook

## Outcome

A new breeder should be live within 14 days after providing required access and assets.

Live means:

- HighLevel account exists.
- Core fields and tags are created.
- Website or storefront is published.
- Lead magnet is live.
- At least one campaign is active.
- Buyer journey is tested end to end.
- Breeder knows how to use the inbox and pipeline.

## Onboarding Timeline

### Day 0: Payment And Intake

- Payment received.
- Intake form sent.
- Access checklist sent.
- Kickoff call scheduled.

### Day 1-2: Account Setup

- Create or access HighLevel sub-account.
- Run setup script.
- Confirm fields, tags, contacts, workflows, and permissions.
- Create project record in internal tracker.

### Day 3-5: Brand And Funnel Build

- Load logo, colors, voice, species, and available animals.
- Build lead magnet page.
- Build storefront or animal gallery.
- Build reservation offer page.
- Configure phone/email sender settings.

### Day 6-8: Workflow Setup

- New lead nurture
- Reservation follow-up
- Purchase confirmation
- Shipping decision workflow
- Care onboarding
- Review/referral workflow
- VIP repeat-buyer list

### Day 9-10: Testing

- Submit a test lead.
- Click reservation offer.
- Trigger purchase webhook with test payload.
- Test shipping decision.
- Confirm email/SMS copy.
- Confirm tags and journey stage updates.

### Day 11-12: Breeder Training

Training agenda:

- Inbox basics
- Contact record basics
- Pipeline basics
- How to add/update animals
- How to approve social posts
- How shipping holds work
- How to pause a workflow

### Day 13-14: Launch

- Publish pages.
- Turn on workflows.
- Send launch links to breeder.
- Schedule first performance review.

## Access Checklist

Ask for:

- HighLevel agency/sub-account access or permission to create one
- Business name and contact details
- Logo and brand colors
- Species and morphs
- Current inventory
- Animal photos
- Price ranges
- Shipping policy
- Refund/deposit policy
- Social links
- Payment processor details
- Upcoming show schedule

## Launch Hand-Off

Send the breeder:

- Storefront URL
- Lead magnet URL
- QR code URL
- Reservation URL
- How to use the inbox
- How to update animal availability
- How to request help
- Date of first review call
